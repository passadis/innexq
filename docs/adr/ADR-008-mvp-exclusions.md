# ADR-008: Exclude Fabric IQ and M365 Copilot publication from the MVP

- **Status:** Accepted
- **Date:** 2026-08-30

## Decision

Do not add Fabric IQ or make Microsoft 365 Copilot/Agent 365 publication a dependency of the core demo. Also exclude a second workflow, multi-tenancy and autonomous negotiation.

## Consequences

Renewal Run remains the first Workflow Pack on a reusable InnexQ product foundation. These capabilities require a changed scenario and an approved ADR before implementation.
