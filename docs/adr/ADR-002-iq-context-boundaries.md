# ADR-002: Separate durable Company IQ from delegated work context

- **Status:** Accepted
- **Date:** 2026-08-30

## Decision

Use Foundry IQ for cited, permission-aware contracts, policies, templates and stable references. Use Work IQ only for recent Microsoft 365 context under the signed-in user's delegated identity.

## Consequences

Background detection cannot impersonate Elena. Work IQ may explain requests and commitments but never supplies pricing, margins, dates or approval authority.
